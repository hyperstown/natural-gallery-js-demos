Natural Gallery demos

The same gallery — infinite scroll, lightbox, likes in IndexedDB, four photo sources — built four ways, so the differences are easy to compare side by side.

  • Old /old

    @ecodev/natural-gallery-js@11.1.3 exactly as released: nothing is ever removed from the DOM, so a long scroll ends up with every figure on the page.

  • First Version /first-demo

    The fork, with its virtualScroll option: only the rows around the viewport exist, and Natural, Masonry and Square layouts can be swapped live.

  • Masonic /masonic

    No natural-gallery at all: React with masonic for the grid and photoswipe for the lightbox, sharing the same data sources and styling.

  • Upstream /upstream

    Upstream master, built from a checkout in demos/upstream/vendor: it trims rows above and below the viewport itself, keeping the DOM small without a virtual mode.

Photos come from picsum.photos, Wikimedia Commons and the Cleveland Museum of Art . None of them are mine.
